## DeepL estimate

The locale registry contains 17 non-English locales. Translating every comment
occurrence into every configured locale is an upper bound of 1377051 source
characters. Exact-comment deduplication lowers this to 1336472.

The inventory needs at least 17 128-KiB source-text batches across all locales,
or 22457 requests with one comment per request.

## Boundaries

The estimate includes every comment containing letters, including technical
notes, disabled code, and directives. Translation suitability requires review.
Markers inside quoted strings and JavaScript regular-expression literals are
excluded. HTML scanning counts HTML comments, while JavaScript and CSS embedded
inside HTML are outside this pass.

Detailed evidence: `build/language/reports/inventory/Comment-Strings.md`.
