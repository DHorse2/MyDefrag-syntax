# MyDefrag Syntax Documentation

MyDefrag Syntax is a VSCodium and Visual Studio Code extension for editing,
navigating, previewing, and validating MyDefrag `.MyD` scripts and `.MyDc`
fragments.

The extension documentation below describes editor behavior. The converted
MyDefrag Help describes the MyDefrag scripting language and the original
MyDefrag program.
